旅橋（静的サイト版）— 2つに分けた zip の1つ目です

GitHub のブラウザ画面からのアップロードは、1ファイル25MBまでのため2つに分けています。
  part1of2: 写真以外のすべて（ページ・データ・プログラム・テスト）＋ 写真の images/hero, images/bg
  part2of2: 残りの写真（images/regions, rt, cat, catsq, herob）

使い方
  1. 2つとも同じフォルダに展開してください（フォルダ構成は同じなので、重ねると元の一式に戻ります）。
  2. 公開するのは project/site/ の中身です（index.html がある階層をサイトのルートにしてください）。
  3. zip のまま GitHub に上げても中身は展開されません。展開したファイルを上げてください。
  4. ブラウザ画面からは1回に100ファイルまでなので、GitHub Desktop か git push をおすすめします。
